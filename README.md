# Mobile-todo-claude

claude codeで作成したtodoアプリ

iPhone での利用に特化した、シンプルなタスク管理 Web アプリです。
HTML / CSS / JavaScript のみで動作し、ビルドやサーバー側の処理は不要です。
データはブラウザのローカルストレージに保存されます。

## 機能

- タスクの追加
- タスクの編集（タスク名をタップ → 詳細シートで変更）
- タスクごとのメモ（詳細シートで入力。一覧にはメモの1行目を表示）
- 親子関係（サブタスク）での管理（親・子・孫・ひ孫の4階層まで）
  - サブタスクの完了数を「1/3」のように表示
  - サブタスクの折りたたみ / 展開
- ドラッグ＆ドロップでの並べ替え・親子関係の変更
- タスクの完了 / 未完了の切り替え（左の丸をタップ）
- タスクの削除（詳細シート内の「タスクを削除」）
- 表示の切り替え（すべて / 未完了 / 完了）
- 完了したタスクの一括削除
- ローカルストレージへの自動保存（再読み込みやアプリ再起動後も保持）
- ダークモード対応（端末の設定に追従）
- ホーム画面に追加すると全画面のアプリとして起動

## ファイル構成

```
index.html   画面の構造（エントリーポイント）
style.css    モバイルファーストのスタイル
app.js       タスク操作・ドラッグ＆ドロップ・ローカルストレージへの保存
```

## 使い方

### 起動する

1. `index.html` をブラウザで開きます。
   - PC で確認する場合はファイルをダブルクリックするだけで動きます。
   - iPhone から開く場合は、リポジトリを GitHub Pages などの静的ホスティングで公開するか、
     同じネットワーク内の PC で簡易サーバーを起動してアクセスします。

     ```sh
     # リポジトリのルートで実行
     python3 -m http.server 8000
     # iPhone の Safari で http://<PCのIPアドレス>:8000/ を開く
     ```

2. （任意）Safari の共有ボタン →「ホーム画面に追加」で、アプリのように全画面で使えます。

### 操作する

| やりたいこと | 操作 |
| --- | --- |
| タスクを追加 | 画面下の入力欄に入力し、「＋」ボタンまたはキーボードの「完了」をタップ |
| タスクを完了にする | タスク左側の丸をタップ（もう一度タップで未完了に戻る） |
| タスクを編集 | タスク名をタップ → 詳細シートで内容を変更して「保存」 |
| メモを書く | タスク名をタップ → 詳細シートの「メモ」に入力して「保存」 |
| サブタスクを追加 | タスク名をタップ →「＋ サブタスクを追加」→ 画面下の入力欄に入力（続けて何件でも追加できます。終えるときは入力欄の上の「×」） |
| 親タスクを変更 | タスク名をタップ → 詳細シートの「親タスク」で選んで「保存」 |
| サブタスクを隠す / 表示 | 親タスク左側の「⌄」をタップ |
| 並べ替え・親子関係の変更 | タスク右端の「≡」をつまんでドラッグ（下記参照） |
| タスクを削除 | タスク名をタップ → 詳細シートの「タスクを削除」（サブタスクも一緒に削除されます） |
| 表示を絞り込む | 上部の「すべて / 未完了 / 完了」をタップ |
| 完了タスクをまとめて削除 | 一覧下の「完了したタスクを削除」をタップ |

### ドラッグ＆ドロップ

タスク右端の「≡」をつまんだまま指を動かします。青い線が移動先を表します。

- **上下に動かす**：並び順を変更
- **右にずらす**：上のタスクのサブタスクにする
- **左にずらす**：親タスクから外す（1段浅くする）
- 親タスクを動かすと、サブタスクもまとめて移動します
- 画面の上端・下端まで動かすと自動でスクロールします
- ドラッグは「すべて」表示のときだけ使えます（絞り込み中は「≡」が表示されません）

### 親子関係と完了の動き

- 親タスクを完了にすると、そのサブタスクもすべて完了になります
- サブタスクを未完了に戻したり、完了済みの親に未完了のサブタスクを追加・移動したりすると、親も未完了に戻ります
- 「未完了」「完了」で絞り込んだときは、条件に合うサブタスクの親も薄い表示で一緒に出します

## データの保存について

- タスクはブラウザの `localStorage`（キー: `mobile-todo.tasks.v1`）に保存されます。
- 以前のバージョンで保存したタスクもそのまま読み込めます（すべて最上位のタスクとして表示されます）。
- データは端末・ブラウザごとに保存され、他の端末とは同期されません。
- Safari の「履歴とWebサイトデータを消去」を行うとタスクも削除されます。
- プライベートブラウズでは保存されない場合があります。
- Safari で開いた場合とホーム画面に追加したアプリでは、保存領域が別になります。

## 動作環境

- iOS 15.4 以降の Safari（`<dialog>` 要素を使用）
- その他の最新ブラウザ（Chrome / Edge / Firefox など）
